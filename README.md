# Women Safety App

## Overview

The **Women Safety App** is a mobile application designed to ensure the safety and security of women in emergency situations. It includes features like real-time location tracking, emergency contacts, a panic button, and nearby medical and police stations to provide quick assistance in case of distress.

## Features

- **Panic Button:** One-click alert for immediate assistance.
- **Emergency Contacts:** Quickly contact pre-defined emergency contacts.
- **Real-Time Location Tracking:** Tracks the user's location and shares it with emergency contacts.
- **Nearby Police Stations & Medical Facilities:** Displays a list of nearby police stations and hospitals for quick access.
- **GPS Tracking:** Sends GPS coordinates to the emergency contact.
